## ⚙️ Instalacja i uruchomienie

```bash
# klonowanie repozytorium
git clone https://git@github.com:bexpe/portfolio.git

# przejście do folderu
cd portfolio

# instalacja zależności
npm install

# uruchomienie projektu
gatsby develop
```

Aplikacja będzie dostępna pod:

```
http://localhost:8000
```

---

## 🏗️ Build produkcyjny

```bash
gatsby build
gatsby serve
```
